# Análisis Muestral con R

## Descripción 

Este proyecto contiene un conjunto de funciones en R para realizar diferentes tipos de muestreo y calcular intervalos de confianza para parámetros poblacionales. Desarrollado como parte de un curso de estadística, proporciona herramientas prácticas para análisis inferencial.

## Funciones

### Tipos de Muestreo
- **Muestreo Simple Aleatorio**
- **Muestreo Sistemático**
- **Muestreo Estratificado**
- **Muestreo Estratificado Proporcional (MEP)**

### Intervalos de Confianza
- **Proporciones** (con y sin población finita)
- **Media Poblacional** (sigma conocida/desconocida, población finita/infinita)
- **Desviación Estándar Poblacional**
- **Varianza Poblacional**

### Cálculo de Tamaños de Muestra
- Para proporciones y medias
- Considerando población finita e infinita
